# smtc2web 新增官方 FTP 站点

为了提升国内用户的下载体验，解决 GitHub 在中国大陆网络不稳导致下载失败问题，官方正式上线新域名 https://download.smtc2web.org 。
此网站为 smtc2web 历史版本的 GitHub 镜像站，同时接入了 Cloudflare CDN，让国内用户下载体验更加友好。
