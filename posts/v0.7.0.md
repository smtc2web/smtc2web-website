## 新功能

- 主题商店：在线浏览、下载安装主题，安装按钮内置下载进度条
- 快速上手引导：安装主题 → 接入 OBS → 准备就绪，可从关于页重放
- 关于页面：版本、常用链接与开源信息
- 主题商店排序下拉改为自绘组件

## 体验与修复

- 托盘：左键显示窗口、右键弹出菜单；轻量模式下「检查更新」不再丢失
- 启动：静态启动外壳消除先露空白页的问题，首帧即标题栏
- Windows 11 改用 DWM 原生圆角，修复双重圆角
- Linux：修复标题栏拖动、托盘左键与任务栏图标
- 进程过滤器保存后自动重载
- 快速上手引导：去商店安装后保留进度并自动续上

## 构建与安全

- 新增 AppImage 打包；修复 fontAwesome 文件名大小写导致的 Linux 构建失败
- 安全审计与主题处理加固；CI 对纯 Markdown 改动跳过构建
- README 重写、Zulip 入口、RepoBeats 统计图；dependabot 依赖升级
