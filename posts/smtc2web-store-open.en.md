## Dear smtc2web users:

smtc2web has now integrated a Theme Store marketplace. Whether you prefer Vibe Coding or crafting themes by hand, we respect your choice. As long as you know any front-end framework (for example, Vue), after some learning you can create a theme, and the theme you make can be published to the smtc2web Theme Store through GitHub Actions or manually.

## Vision

We hope that in the future, smtc2web will accompany every streamer through every livestream, safe and stable, and the Theme Store ecosystem will have 100+ themes.

## Installing the development tool

### Prerequisites

- Rustup

Run the following command to install the `smtc2web-dev` command-line tool:

```bash
## Repo：https://github.com/smtc2web/smtc2web-dev.git
cargo install smtc2web-dev
```
