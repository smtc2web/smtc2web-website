category: "Announcements"

Recently, after updating to the latest version of Windows 11, smtc2web began hanging at one step of the installation for a long time. The affected versions are estimated to be 0.4.0 through 0.6.7. Please update smtc2web to the latest version as soon as possible to resolve the issue. The NSIS installer will gradually be phased out in favor of an installer based on Windows Installer, for a more stable update process.
