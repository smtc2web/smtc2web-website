## Version v0.1.8

### New features
- **System tray support**
  - Added system tray support for the app, providing convenient menu operations
  - The tray menu includes the following features:
    - Open webpage: quickly access the app interface
    - Open configuration file: edit the configuration directly
    - Restart app: restart the app with one click
    - Exit app: safely quit the program
  - Note: in this version the tray icon is not implemented yet; the feature works but no icon is shown

### Improvements
- **Time display format improvements**
  - Improved the API output format: changed time from seconds to MM:SS format
  - Improved the frontend display: removed frontend time formatting logic and directly used the backend-formatted time string
  - Improved user experience: time display is more intuitive and readable

### Technical updates
- **Dependency updates**
  - Replaced the tray library: switched from `tray-item` to `systray`
  - Added a dependency: added the `open` library for opening webpages and configuration files
  - Version upgrade: app version upgraded from 0.1.7 to 0.1.8

### Project maintenance
- **GitHub template improvements**
  - Bug report template: automatically adds the `bug` label
  - Feature request template: automatically adds the `enhancement` label
- **Build configuration updates**
  - Updated `.gitignore` to ignore `*.txt` files

### File changes
- Added file: `src/tray.rs` - tray feature implementation
- Modified files:
  - `src/main.rs` - integrated tray feature and time formatting
  - `Cargo.toml` - updated dependencies and version number
  - `frontend/index.html` - adjusted time display
  - `frontend/main.js` - simplified time handling logic
  - `.github/ISSUE_TEMPLATE/` - improved issue templates
  - `.gitignore` - updated ignore rules

### Installation and upgrade

```bash
# 克隆仓库
git clone https://github.com/smtc2web/smtc2web.git
cd smtc2web

# 编译和运行
cargo build --release
cargo run --release
```

### Known issues

- The tray icon feature is not implemented yet; the tray area shows a blank icon
- This issue does not affect the normal use of the tray menu
