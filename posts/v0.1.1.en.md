## About smtc2web

smtc2web is a tool that syncs Windows 11 media session information to the web, letting you view the current playback state and track information in a browser and control playback.

This version is the first official release and includes basic media information reading and web display features.

> Future versions are under continuous iteration — stay tuned for project updates.
