## v0.3.1

### Removed

- The display console feature — replaced by log files (%appdata%\smtc2web\logs)

### Changed

- Icons switched from Emoji to Font Awesome icons
- The storage location of Skills was changed, and a YAML header was added to each Skill
- Removed the tray menu separator
