## New features

- Theme Store: browse, download, and install themes online, with a built-in download progress bar in the install button
- Onboarding guide: install a theme → connect to OBS → ready to go; can be replayed from the About page
- About page: version, common links, and open-source information
- The Theme Store sort dropdown is now a custom-drawn component

## Experience and fixes

- Tray: left-click shows the window, right-click opens the menu; "Check for updates" is no longer lost in Lightweight Mode
- Startup: a static startup shell eliminates the blank page that appeared first, so the first frame is the title bar
- Windows 11 now uses native DWM rounded corners, fixing double rounded corners
- Linux: fixed title bar dragging, tray left-click, and the taskbar icon
- The process filter reloads automatically after saving
- Onboarding guide: progress is kept after installing from the store and resumes automatically

## Build and security

- Added AppImage packaging; fixed Linux builds failing due to fontAwesome filename casing
- Security audit and hardened theme handling; CI skips builds for Markdown-only changes
- README rewrite, Zulip entry point, RepoBeats stats chart; dependabot dependency upgrades
