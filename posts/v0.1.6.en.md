## Version 0.1.6 - Optimized update logic

### 🚀 Key improvements

#### 1. Smart update logic
- **Backend update mechanism**:
  - Added playback state detection (`is_playing` field)
  - Implemented a smart update strategy to avoid unnecessary duplicate updates
  - Added a timestamp mechanism to ensure forced updates (every 5 seconds)
  - Dynamically adjusted the polling interval: 100ms while playing, 200ms while paused

- **Frontend update optimizations**:
  - Implemented data change detection to avoid redundant rendering
  - Dynamically adjusted the polling frequency: 100ms while playing, 200ms while paused
  - Improved error handling; a 250ms default interval is used on errors

#### 2. Data structure improvements
- **Song struct**:
  - Added the `is_playing: bool` field to indicate the current playback state
  - Added the `last_update: u64` field for timestamp management
  - Derived the `PartialEq` trait to support struct comparison

#### 3. Error handling improvements
- Strengthened error handling for Windows API calls
- Added handling for session manager acquisition failures
- Improved the error handling pattern for async operations

#### 4. Performance optimizations
- Reduced unnecessary state writes
- Optimized the polling mechanism to lower CPU usage
- Implemented dynamic update frequency based on playback state

### 📝 Documentation updates
- **README.md**:
  - Improved the build dependency instructions
  - Listed the main dependencies and their versions in detail
  - Separated the Windows-specific dependency instructions
  - Improved the document structure and readability
