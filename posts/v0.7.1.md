各位用户，我要向大家道歉，事情的起因是这样的。

2026年11月4日10时33分，我发布了一个最伟大的 v0.7.0 版本，但是作为第一个下载更新的我，我发现了一个严重的问题：**图标太大了！**

后续我紧急修复了这个 Bug，并发布了 v0.7.1 版本，这个版本已修复这个 Bug，顺便对 vue-i18n 进行了安全更新。

---

这是怎么发生的？其实，根据 DeepSeek 的分析：

## 修复内容

**根因**：Tauri 生产构建会为 `index.html` 的内联样式注入 CSP nonce。按 CSP 规范，一旦存在 nonce，`style-src` 中的 `'unsafe-inline'` 会被忽略。FontAwesome 默认在运行时插入 `<style>`，因此被拦截，图标 SVG 失去尺寸约束，出现：

- 操作栏图标过大、文字被挤成竖排
- 标题栏导航图标消失

**修改**：

- `src/main.ts`：静态导入 `@fortawesome/fontawesome-svg-core/styles.css`，让图标样式随应用 CSS 一起打包。
- `src/config/fontAwesome.ts`：设置 `config.autoAddCss = false`，避免运行时重复注入。

## 验证

- 本地复现了与截图一致的异常，修复后图标与标题栏均恢复正常。
- `pnpm build`（含 `vue-tsc` 类型检查）通过。
- Release 工作流全部任务成功：Windows x64/arm64、Linux x64/arm64、`finalize` 均完成。
