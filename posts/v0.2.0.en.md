## v0.2.0

### Major update

- **Framework migration**: migrated the entire project from the original implementation to the Tauri framework
  - Added the Tauri configuration file (`tauri.conf.json`)
  - Added a build script (`build.rs`)
  - Created a brand-new frontend asset structure

### New features

- **System tray**: implemented full system tray support
  - Added a tray icon and menu
  - Improved the system tray interaction experience
  - Added minimize-to-tray support

### Build and deployment

- **CI/CD integration**: added GitHub Actions workflows
  - Added a build workflow (`.github/workflows/build.yml`)
  - Added a nightly build workflow (`.github/workflows/build-nightly.yml`)
  - Supports automated build and release workflows

### Project structure

- **Code refactoring**: reorganized the project structure
  - Created the `src-tauri/` directory for Tauri backend code
  - Implemented the configuration management module (`config.rs`)
  - Added the console feature (`console.rs`)
  - Implemented system tray management (`tray.rs`)
  - Updated the main program entry point (`main.rs`)

### Development environment

- **Development tools**: improved the developer experience
  - Added VS Code extension recommendations (`.vscode/extensions.json`)
  - Updated `.gitignore` with frontend development ignore rules
  - Removed the old `Cargo.lock` file

### Documentation and configuration

- **Documentation updates**: updated the project documentation for the new framework
- **Configuration improvements**: improved the app configuration and build settings

### Performance and stability

- **Performance improvements**: improved app performance through the Tauri framework
- **Stability improvements**: improved error handling and system compatibility
