## 亲爱的 smtc2web 用户们：

如今 smtc2web 已集成主题商店市场，无论你是喜欢 Vibe Coding 还是自己手搓主题，我们都尊重您的选择。只要您会任何一种前端框架（例如 Vue），经过一些学习，您可以制作出一个主题，并且您自己制作的主题可以通过 GitHub Actions 或者手动发布至 smtc2web 主题商店。

## 愿景

我们希望在未来，smtc2web 将成为每一个陪伴主播的每一次直播，并且安全稳定，主题商店生态拥有 100+ 主题。

## 安装开发工具

### 前提条件

- Rustup

执行以下命令即可安装 `smtc2web-dev` 命令行工具：

```bash
## 仓库：https://github.com/smtc2web/smtc2web-dev.git
cargo install smtc2web-dev
```
