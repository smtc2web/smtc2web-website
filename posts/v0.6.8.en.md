## Fixed

### src-tauri/installer_hooks. nsh:

1. Hang: add a timeout to both broadcasts → SendMessage ${HWND_BROADCAST} ${WM_SETTINGCHANGE} 0 "STR:Environment"
TIMEOUT=1000
2. Wrong hive selected: switch to a single
!macro SMTC_PATH_HELPERS that generates one set of functions for HKCU/HKLM (the root key is a literal, not dependent on macro expansion timing), and inside the Hook macro use !if "${INSTALLMODE}" to choose the function. The Hook macro is expanded inside a Section, by which point INSTALLMODE is already defined.
