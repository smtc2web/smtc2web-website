## What's changed

This version is a nightly build and includes the following updates:

### New features

- Added a nightly build workflow for more timely continuous integration
- The percentage display now shows one extra decimal place for improved precision

### Changes

- Adjusted the version number naming convention to distinguish nightly builds
- Added Single Instance Lock related dependencies in preparation for the upcoming Tauri migration

> Nightly builds may be unstable and are for testing only.
