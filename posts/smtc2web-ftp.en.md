To improve the download experience for users in China and solve download failures caused by unstable GitHub connectivity in mainland China, we have officially launched a new domain: https://download.smtc2web.org .
This site is a GitHub mirror for historical smtc2web versions and is also behind the Cloudflare CDN, making downloads friendlier for users in China.
